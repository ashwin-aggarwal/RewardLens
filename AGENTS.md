# RewardLens Agent Instructions

These instructions apply to all future development sessions in this repository.

- Read `CONTEXT.md` before beginning any substantial task.
- Understand the research question and the current experimental phase before changing code.
- Prioritize scientific correctness, reproducibility, and visual storytelling.
- Keep the codebase simple; avoid premature abstraction and complexity.
- Never fabricate experiment results. Clearly label planned behavior, demonstrations, and verified findings.
- Distinguish scripted demonstrations from behavior learned by an agent.
- Generate readable diagrams, GIFs, and plots whenever they improve understanding.
- Run relevant tests after modifications.
- Update `CONTEXT.md` after every meaningful milestone, including status, decisions, verified results, unresolved issues, and the next logical step.
- Preserve previous experimental decisions unless there is a clear reason to revise them; document any revision and its rationale.
- Stop at the requested phase. Do not automatically implement future phases.

## Git Ownership

Claude Code and Codex may stage, commit, and push changes only when explicitly authorized by the user. Authorization is limited to the specific requested operation and does not carry over to future tasks.

`CONTEXT.md` is the authoritative research log. Keep it concise and evidence-based rather than accumulating redundant session summaries.
